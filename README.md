## 🌸 About Me

> *I started out curious about what a screen looks like. Now I'm curious about what happens behind it.*

I'm a **Software Engineering undergraduate** who began with an interest in UI and frontend development, but gradually became far more interested in what happens behind the screen — APIs, databases, backend architecture, and how the different parts of a system fit together.

My main foundation is **Java and backend development**, particularly Spring Boot, REST APIs, SQL and database-driven applications. I'm now expanding into full-stack development with the **MERN stack** to understand different approaches to building modern web applications.

I learn by actually building things — academic projects, experiments with new tech, GitHub workflows, APIs, deployment and system design. Working on full-stack projects has taught me something beyond programming too: how to juggle several moving parts of a system at once, stay inside scope, and turn an idea into something that actually runs.

I'm still learning, experimenting, and figuring out what kind of developer I want to become. Long term, I'm drawn to **software architecture** — building systems that aren't just functional, but thoughtfully designed.
